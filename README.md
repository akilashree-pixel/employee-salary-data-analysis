# 📊 Employee Salary Analysis using Python

## Overview
This project demonstrates the complete data analysis workflow, from cleaning raw employee data to generating meaningful insights through visualization. The dataset was processed to handle missing values and duplicate records, followed by Exploratory Data Analysis (EDA) to identify trends in salary, experience, and department-wise performance.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Key Features
- Data cleaning and preprocessing
- Missing value handling
- Duplicate record removal
- Exploratory Data Analysis (EDA)
- Statistical analysis
- Data visualization and reporting

## Key Insights
- Employees with greater experience generally earn higher salaries.
- Salary distribution highlights variations across employees.
- Department-wise analysis reveals differences in average compensation.
- Experience and salary show a positive correlation.
- Visualizations help uncover patterns that are not immediately visible in raw data.
